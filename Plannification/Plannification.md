# Planification de projet
### Phase 1 : Analyse (1 semaine)
Analyse du cahier des charges.

Définition des pages :
  Accueil, Catalogue, Détails, Panier, Commander, Espace admin.

Création des maquettes (wireframes / maquettes).

### Phase 2 : Conception & Base de Données (1 semaine)
Réalisation du MCD / MLD.

Création des tables.

Configuration de la base de données dans MySQL.

### Phase 3 : Développement Front-end (2 semaines)
Intégration HTML.

Styling avec CSS (Modern UI).

Interactivité avec JavaScript.

### Phase 4 : Développement Back-end (2 semaines)
Configuration de PHP et MySQL.

Connexion à la base de données avec PDO.

Développement des fonctionnalités :
Affichage des produits.

Gestion du panier (sessions).

Système de commande.

Gestion des clients.

Espace admin :
Ajouter / modifier / supprimer produits.

Gestion du stock.

Gestion des commandes (statut).

Sécurisation :

Protection SQL Injection.

Validation des formulaires.

### Phase 5 : Tests & Déploiement (1 semaine)
Tests des fonctionnalités.

Correction des bugs.

Optimisation du site.
